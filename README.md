# Groove – Spotify Clone

Music streaming app with FastAPI, Supabase, Saavn API, and Nova AI.

## Stack
- Frontend: HTML / CSS / Vanilla JS
- Backend: FastAPI
- Auth & DB: Supabase
- Music: https://saavn.sumit.co
- AI Chat: Gemini

## Local run
See setup notes in this repo. Production: Render (API) + Vercel (frontend).
